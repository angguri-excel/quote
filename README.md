# 견적서 웹 계산기

- `index.html`을 브라우저로 열면 바로 동작합니다.
- 품목을 고르면 단위·단가가 자동으로 들어가고, 수량×단가=금액, 공급가액·부가세(10%, 원 단위 반올림)·합계가 계산됩니다.
- 합계는 "일금 ○○원정" 한글로도 표시됩니다.
- 상단 [인쇄 / PDF 저장] → 프린터를 'PDF로 저장'으로 고르면 A4 PDF가 됩니다.
- [품목 관리]는 **새 창**으로 열려서 작성 중인 견적서가 그대로 남습니다. 품목 관리 창의 [견적서로 돌아가기]는 그 창을 닫습니다.
- 작성 중인 내용(견적번호·수신·수량·품목)은 **이 브라우저에만 임시 저장**되어 새로고침해도 남습니다. 서버로 보내지 않습니다. 처음부터 다시 쓰려면 [새 견적서]를 누릅니다.
- 작성 중에 페이지를 닫거나 새로고침·이동하려 하면 브라우저가 **나갈지 묻는 경고**를 띄웁니다(문구는 브라우저가 정합니다). 아무것도 건드리지 않았거나 [새 견적서]를 누른 경우에는 뜨지 않습니다.

## 품목 관리 (items.csv)
- 품목표는 `items.csv`(품목, 단위, 단가)이고 엑셀로 열어 고쳐도 됩니다. 가상의 사무용품 업체 데이터입니다.
- [품목 관리](새 창)에서 품목을 고치고 [CSV 저장]을 누르면 내 컴퓨터에 `items.csv`로 저장되고 이 브라우저의 견적서에 바로 반영됩니다.
- **데모 사이트는 포트폴리오라 서버에는 저장되지 않습니다.**
- `index.html` 안의 `items-data` 블록은 `items.csv`를 읽지 못할 때 쓰는 예비 목록입니다.
