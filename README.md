# 견적서 웹 계산기

- `index.html`을 브라우저로 열면 바로 동작합니다. (서버·설치 불필요)
- 품목을 고르면 단위·단가가 자동으로 들어가고, 수량×단가=금액, 공급가액·부가세(10%, 원 단위 반올림)·합계가 계산됩니다.
- 합계는 "일금 ○○원정" 한글로도 표시됩니다.
- 상단 [인쇄 / PDF 저장] → 프린터를 'PDF로 저장'으로 고르면 A4 PDF가 됩니다.

## 품목 관리 (items.csv)
- 품목표는 `items.csv`(품목, 단위, 단가)에 있습니다. 엑셀로 열어 고쳐도 됩니다. 가상의 사무용품 업체 데이터입니다.
- 상단 [품목 관리]를 누르면 `items.html`이 열립니다. 품목을 추가·수정·삭제한 뒤 [CSV 저장]을 누르면 됩니다.
- 작성 중인 내용은 자동으로 임시 저장되어 F5를 눌러도 남습니다. 저장된 품목표로 되돌리려면 [품목 새로고침]을 누릅니다.
- [CSV 저장]을 하면 열려 있는 견적서 화면(`index.html`)의 품목 목록이 바로 갱신됩니다.
- 크롬·엣지는 저장 위치를 물어보니 이 폴더의 `items.csv`를 골라 덮어씁니다. 다른 브라우저는 내려받기 폴더에 저장되니 이 폴더로 옮깁니다.
- 파일을 그냥 열면(file://) 브라우저 보안 때문에 `items.csv`를 자동으로 읽지 못합니다. 처음 한 번 [품목 CSV 불러오기]로 `items.csv`를 고르면 그 브라우저에 기억해 둡니다.
- 웹 서버나 호스팅(http)에 올려 두면 `items.csv`를 자동으로 읽습니다.
- `index.html` 안의 `items-data` 블록은 `items.csv`를 읽지 못할 때 쓰는 예비 목록입니다.
